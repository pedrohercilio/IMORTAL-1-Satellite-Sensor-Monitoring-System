# IMORTAL-1- Sensor Analysis System - C
Projeto em C que simula um Módulo de Controle Espacial de Satélite que tem como função principal coletar e analisar dados numéricos de sensores em órbita.

-> Objetivo:

Sistema desenvolvido em linguagem C para simular o módulo de controle espacial do satélite experimental IMORTAL-1, responsável pelo monitoramento e análise de leituras de sensores em órbita. O projeto realiza cálculos estatísticos, verificação de segurança dos dados e geração de relatórios completos a partir de três leituras numéricas. O projeto tem como objetivo simular um sistema embarcado simples de monitoramento espacial, aplicando fundamentos de programação procedural e lógica computacional em um cenário inspirado em sistemas reais de telemetria e análise orbital.

-> Foco:

modularização utilizando funções;
manipulação de dados numéricos;
estruturas condicionais e de repetição;
organização de código em C;
interação via terminal;
relatórios e feedback visual utilizando ANSI Colors.


-> Funcionalidades:

Cálculo da média das leituras;
Identificação do valor máximo e mínimo;
Cálculo do desvio de cada leitura em relação à média;
Verificação de faixa segura de operação;
Geração de barra gráfica proporcional à intensidade média;
Relatório completo com todas as análises;
Interface colorida no terminal;
Sistema de repetição de operações e simulações.


-> Conceitos Aplicados:

Funções com parâmetros fixos;
Estruturas condicionais (if, else, switch);
Estruturas de repetição (while, for);
Modularização;
Validação de entrada;
Formatação de saída;
Estatística básica.
